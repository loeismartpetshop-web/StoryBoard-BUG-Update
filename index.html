SCENE 10

ระบบล็อกแอดมิน (Multi-Admin Lock)

CONCURRENT EDIT PROTECTION

ป้องกัน data race เมื่อมีแอดมิน 2-3 คนเข้าระบบหลังบ้านพร้อมกัน — ระบบจะล็อกหมวด/สินค้าที่กำลังถูกแก้ และแสดง overlay สีดำ-เทา + ไอคอน lock ให้แอดมินคนอื่นเห็นทันทีว่ามีใครกำลังทำงานอยู่

T = 0s
Admin 1 เข้าระบบ

คลิกหมวด "อาหารสุนัข" เพื่อเริ่มแก้ → ระบบขอ lock

T = 0.3s
Lock Acquired ✓

Admin 1 ได้สิทธิ์แก้ · แถบสถานะเขียว · เริ่มแก้ชื่อ/ภาพ

T = 5s
Admin 2 เข้า

เปิดหลังบ้าน → poll สถานะ → เห็นว่า "อาหารสุนัข" lockedอยู่

T = 5.1s
Overlay ขึ้น

Admin 2 เห็น overlay สีดำ + ไอคอน lock + ชื่อ Admin 1

T = 90s
Auto Release

Admin 1 ออกจากหน้า → lock ปล่อยอัตโนมัติ · Admin 2 เห็นทันที
